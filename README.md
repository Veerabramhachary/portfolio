## 🚀 Quick Start
Clone and run loacally in vs Code (Windows 11 workflow):

1. **Clone the repo**
     ```blash
     git clone https://github.com/veerabramhachary/portfolio.git
     cd portfolio
2. **Install dependencies**
   npm install
3. **Run development sever**
   npm run dev
   Opens at http:localhost:5173
